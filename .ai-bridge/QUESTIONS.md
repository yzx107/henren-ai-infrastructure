# 待判断问题

以下问题应由投资负责人或 reviewer 决定；Codex 不应自行猜测后继续扩建。

## 投资定义

1. “直接-高/中/低”收入暴露的量化门槛是什么：收入占比、订单占比、客户 CapEx 敏感度，还是多条件组合？
2. 云厂商总 CapEx 中，土地建筑、服务器、网络、融资租赁和自研芯片如何拆分；哪些允许视为 AI CapEx？
3. “二级受益”最多允许几跳，路径置信度如何衰减？
4. “尚未充分定价”最低需要哪些可观察量：一致预期修正、估值分位、事件后超额收益、拥挤度？
5. A/H/US 比较时，以公司实体还是主证券为研究单位；ADR、A/H 折溢价如何处理？

## 数据语义

1. 是否新增 `first_available_at TIMESTAMPTZ`，并保留 `disclosed_at DATE` 作为自然日？
2. `valid_from` 应统一表示法律协议生效、商业交付开始、产品量产，还是关系在研究模型中生效？是否需要独立字段？
3. 来源后来修订时，是覆盖原记录还是保存 immutable version 与 `superseded_at`？
4. `economic_exposure` 目前是文字；下一版是否要求币值、数量、容量、收入占比及单位？
5. 财务期末、公告时间、供应商到达时间和入库时间应如何分别命名？
